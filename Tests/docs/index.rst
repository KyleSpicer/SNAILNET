SnailNet Test Suite
===================

API reference for the harness that drives
`SnailNet <https://gitea.com/4-Projects/SNAILNET>`_ in its end to end tests,
generated from the docstrings in ``snailnet_tests``. Read it when writing a
new test.

For running the suite, reading its output, and what each test proves, see
``Docs/testguide.md`` in the repository.
